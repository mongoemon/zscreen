# Zcreenshot

โปรแกรมต่อภาพสกรีนช็อต: วางหรือลากรูปเข้ามา แล้วจัดเรียง ย่อ/ขยาย ก่อนบันทึกเป็นไฟล์ PNG ภาพเดียว

ใช้งานได้ 2 แบบ:

| แบบ | เหมาะกับ | ฟีเจอร์เฉพาะ |
|-----|----------|---------------|
| **Desktop (Electron)** | Windows / macOS | ไอคอนใน System Tray, ปุ่มลัดทั้งระบบ `Ctrl/Cmd+Shift+V`, เปิดพร้อมเครื่อง |
| **Web / PWA** | เปิดผ่านเบราว์เซอร์ หรือติดตั้งเป็นแอป | ไม่ต้องติดตั้งโปรแกรม, โฮสต์บน static server ได้ |

### Desktop กับ Web ต่างกันอย่างไร

ฟีเจอร์แก้ไขภาพ (วาง/ลากรูป, จัดวาง, เครื่องมือวาด, Undo, บันทึก PNG, คัดลอก) และหน้าแก้ไขวิดีโอ **ใช้ได้เหมือนกันทั้งสองแบบ** ที่ต่างกันมีดังนี้

| หัวข้อ | Desktop (Electron) | Web / PWA |
|--------|--------------------|-----------|
| การติดตั้ง | ติดตั้งโปรแกรม (Windows: Setup / Portable, macOS: `.dmg`) | ไม่ต้องติดตั้ง เปิดในเบราว์เซอร์ หรือกดติดตั้งเป็น PWA |
| การอัปเดต | ต้องติดตั้งเวอร์ชันใหม่เอง | ได้เวอร์ชันล่าสุดอัตโนมัติเมื่อเปิดหน้าเว็บ |
| ใช้งานออฟไลน์ | ได้เสมอ | ได้หลังเปิดผ่าน `http(s)` ครั้งแรก (Service Worker เก็บไฟล์ไว้) |
| System Tray | มี: ปิดหน้าต่างแล้วโปรแกรมยังทำงานอยู่, มีเมนูลัด | ไม่มี |
| เปิดพร้อมเครื่อง | ตั้งได้จากเมนู Tray | ไม่มี |
| ปุ่มลัดทั้งระบบ | วางรูปจากคลิปบอร์ด, เปิด/เริ่ม/หยุดบันทึกหน้าจอ และจับภาพแบบเลื่อนหน้าจอ ได้จากทุกโปรแกรม (ค่าเริ่มต้น `Ctrl/Cmd + Shift + V`, `Ctrl/Cmd + Alt + R`, `Ctrl/Cmd + Alt + S`) | ไม่มี (ปุ่มลัดใช้ได้เฉพาะตอนหน้าเว็บโฟกัสอยู่) |
| ตั้งค่าปุ่มลัด | เปลี่ยนได้ทุกปุ่ม รวมถึงปุ่มลัดทั้งระบบ (เก็บใน `shortcuts.json` ของแอป) | เปลี่ยนได้ทุกปุ่มที่ใช้ในหน้าเว็บ (เก็บในเบราว์เซอร์ แยกตามเบราว์เซอร์/เครื่อง) |
| ปุ่ม **Paste** / **Copy** | ใช้ได้เสมอ | ต้องเปิดผ่าน `localhost` หรือ HTTPS และเบราว์เซอร์อาจขอสิทธิ์ (ถ้าใช้ไม่ได้ให้กด `Ctrl/Cmd + V`) |
| ประวัติคลิปบอร์ด | เก็บรูปที่**คัดลอกจากทุกโปรแกรม** 10 รูปล่าสุด (โปรแกรมคอยดูคลิปบอร์ดตลอด) | เก็บเฉพาะรูปที่วาง/ลาก/เลือกไฟล์**ในแท็บนี้** 10 รูปล่าสุด (หายเมื่อรีเฟรช) |
| บันทึกหน้าจอ: เลือกสิ่งที่บันทึก | หน้าต่างเลือกของแอปเอง มีภาพตัวอย่าง *ทั้งหน้าจอ* / *หน้าต่าง* | หน้าต่างเลือกของเบราว์เซอร์ (หน้าจอ / หน้าต่าง / แท็บ ขึ้นกับเบราว์เซอร์) |
| บันทึกหน้าจอ: ระหว่างบันทึก | ซ่อนหน้าต่าง Zcreenshot ได้ จึงไม่ติดอยู่ในวิดีโอ | หน้าเว็บยังแสดงอยู่ ถ้าบันทึกทั้งหน้าจอจะติดหน้าต่างเบราว์เซอร์ไปด้วย |
| บันทึกหน้าจอ: วิธีหยุด | ปุ่มหยุด, คลิกไอคอน Tray, เมนู Tray หรือปุ่มลัดบันทึกหน้าจอ (ค่าเริ่มต้น `Ctrl/Cmd + Alt + R`) | ปุ่มหยุด หรือปุ่ม "หยุดแชร์" ของเบราว์เซอร์ |
| จับภาพแบบเลื่อนหน้าจอ | เลือกหน้าต่างจากรายการของแอป, ซ่อนหน้าต่าง Zcreenshot ได้, หยุดด้วยปุ่มลัดทั้งระบบ (ค่าเริ่มต้น `Ctrl/Cmd + Alt + S`) หรือ Tray | เลือกผ่านหน้าต่างของเบราว์เซอร์ (แท็บอื่นก็ได้) · Chrome/Edge จับภาพต่อได้แม้แท็บนี้อยู่เบื้องหลัง |
| บันทึกหน้าจอ: สิทธิ์ | macOS ต้องอนุญาต Screen Recording ให้แอปใน System Settings ครั้งแรก | เบราว์เซอร์ถามทุกครั้งที่เริ่มบันทึก (macOS ต้องอนุญาต Screen Recording ให้ตัวเบราว์เซอร์) |
| บันทึกเป็น MP4 | ได้ถ้าระบบปฏิบัติการเข้ารหัส H.264 ได้ | ขึ้นกับเบราว์เซอร์ (ถ้าไม่รองรับจะมีแค่ GIF / WebM / ไฟล์ต้นฉบับ) |
| การบันทึกไฟล์ (PNG / GIF / วิดีโอ) | มักมีหน้าต่างให้เลือกตำแหน่งก่อนบันทึก | ดาวน์โหลดตามการตั้งค่าของเบราว์เซอร์ (มักลงโฟลเดอร์ Downloads) |
| จำนวนหน้าต่าง | เปิดได้ครั้งละ 1 หน้าต่าง เปิดซ้ำจะดึงหน้าต่างเดิมขึ้นมา | เปิดหลายแท็บได้ แต่ละแท็บแยกกัน |

> การเปิดไฟล์ `index.html` ตรง ๆ (หัวข้อ 4 ด้านล่าง) ทำงานแบบ Web แต่ติดตั้งเป็น PWA ไม่ได้ และปุ่ม Paste / Copy อาจใช้ไม่ได้

## การเข้าถึง / การติดตั้ง

### 1) Desktop (Windows)

ไฟล์ติดตั้งอยู่ในโฟลเดอร์ `dist/` (หลังสั่ง `npm run dist:win`):

- `Zcreenshot Setup 1.0.0.exe` — ตัวติดตั้ง (NSIS)
- `Zcreenshot 1.0.0.exe` — แบบ Portable ดับเบิลคลิกใช้ได้เลย ไม่ต้องติดตั้ง

### 2) รันจากซอร์สโค้ด

ต้องมี [Node.js](https://nodejs.org/) ติดตั้งไว้

```bash
npm install
npm start
```

### 3) Web / PWA

```bash
npm run build:web   # สร้างไอคอนและคัดลอกไฟล์ไปที่ ./web
npm run serve:web   # เปิดเซิร์ฟเวอร์ที่ http://localhost:5173
```

- เปลี่ยนพอร์ตได้ด้วยตัวแปร `PORT` เช่น `PORT=8080 npm run serve:web` (PowerShell: `$env:PORT=8080; npm run serve:web`)
- เซิร์ฟเวอร์ผูกกับ `127.0.0.1` เท่านั้น จึงเข้าจากเครื่องอื่นในเครือข่ายไม่ได้
- `localhost` นับเป็น secure context จึงกดติดตั้งเป็น PWA ได้ (ไอคอนติดตั้งในแถบ address bar)
- ถ้าจะให้คนอื่นเข้าถึง ให้นำโฟลเดอร์ `web/` ไปโฮสต์บน static server ใดก็ได้ที่เป็น **HTTPS** (เช่น GitHub Pages, Netlify, Cloudflare Pages) เพราะ Service Worker และการเข้าถึงคลิปบอร์ดต้องใช้ HTTPS

### 4) เปิดไฟล์ `index.html` ตรง ๆ (แบบเร็วที่สุด)

ดับเบิลคลิก `index.html` ที่โฟลเดอร์หลักเพื่อเปิดในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งหรือรันเซิร์ฟเวอร์

- ใช้ได้: วางด้วย `Ctrl/Cmd + V`, ลากไฟล์มาวาง, เลือกไฟล์, จัดวาง, ซูม, Undo และ Save PNG
- ติดตั้งเป็น PWA ไม่ได้ เพราะ Service Worker ลงทะเบียนเฉพาะตอนเปิดผ่าน `http(s)`
- ปุ่ม **Paste** และ **Copy** อาจใช้ไม่ได้ในบางเบราว์เซอร์ เพราะ Clipboard API มักต้องการ secure context ถ้าใช้ไม่ได้ ให้กด `Ctrl/Cmd + V` แทน
- ไอคอนแท็บอาจไม่ขึ้น (ไฟล์ไอคอนอยู่ใน `build/`) ไม่กระทบการใช้งาน
- ไม่มีฟีเจอร์ Tray และปุ่มลัดทั้งระบบ (เฉพาะแอป Desktop)

> หัวข้อนี้เขียนจากการอ่านโค้ด ยังไม่ได้ทดสอบกับทุกเบราว์เซอร์ ถ้าต้องการให้ครบทุกฟีเจอร์ ให้ใช้วิธีที่ 3 (Web / PWA)

## วิธีใช้งาน

### เพิ่มรูป

| วิธี | ทำอย่างไร |
|------|-----------|
| วางจากคลิปบอร์ด | กด `Ctrl/Cmd + V` หรือปุ่ม **Paste** |
| ลากไฟล์มาวาง | ลากไฟล์รูป (หลายไฟล์ได้) มาปล่อยในหน้าต่าง |
| เลือกไฟล์ | ปุ่ม **เพิ่มรูป…** |
| ปุ่มลัดทั้งระบบ (Desktop) | `Ctrl/Cmd + Shift + V` จากที่ไหนก็ได้ — โปรแกรมจะเด้งขึ้นมาพร้อมรูปจากคลิปบอร์ด |

รูปใหม่จะถูกต่อท้ายด้านล่างของรูปเดิมโดยอัตโนมัติ

### จัดวางรูป

- **ย้าย** — ลากรูป (รูปที่คลิกจะขึ้นมาอยู่ด้านหน้า)
- **ปรับขนาด** — ลากจุดสี่เหลี่ยมสีส้มที่มุมขวาล่างของรูปที่เลือก (คงสัดส่วนเดิม)
- **เรียงแนวตั้ง** — จัดทุกรูปเรียงจากบนลงล่างให้ชิดซ้าย
- **เลื่อนมุมมอง** — กด `Space` ค้างแล้วลาก, ลากปุ่มกลางเมาส์, ลากที่พื้นที่ว่าง หรือใช้ล้อเมาส์/ทัชแพด
- **ซูม** — `Ctrl/Cmd + ล้อเมาส์`, `Ctrl/Cmd + +` / `-`, ปุ่ม **Fit** หรือ `Ctrl/Cmd + 0` เพื่อพอดีหน้าจอ
- **Undo** — `Ctrl/Cmd + Z` (ย้อนได้ 50 ขั้น)
- **ลบ** — เลือกรูปแล้วกด `Delete` / `Backspace` หรือปุ่ม **ลบ**; **ล้างทั้งหมด** เพื่อเริ่มใหม่
- กด `Esc` เพื่อยกเลิกการเลือก

### บันทึกหน้าจอเป็นวิดีโอ / GIF

1. กดปุ่ม **บันทึกหน้าจอ** (ไอคอนกล้องวิดีโอ) บนแถบเครื่องมือ หรือเมนู Tray → *บันทึกหน้าจอ…* (Desktop)
2. เลือก **ขนาดวิดีโอ** (ขนาดเดิม / 1080p / 720p / 480p / 360p / 240p — นับจากด้านสั้น ไม่ขยายเกินต้นฉบับ) และ **เฟรมเรต** (15 / 30 / 60 fps)
3. เลือกสิ่งที่จะบันทึก
   - **Desktop**: เลือกจากรายการ *ทั้งหน้าจอ* หรือ *หน้าต่าง* (มีภาพตัวอย่าง) — ค่าเริ่มต้นจะซ่อนหน้าต่าง Zcreenshot ระหว่างบันทึก
   - **Web**: กดเริ่มแล้วเบราว์เซอร์จะถามเองว่าจะแชร์หน้าจอ หน้าต่าง หรือแท็บไหน
4. หยุดด้วยปุ่ม **หยุด**, คลิกไอคอน Tray หรือปุ่มลัดบันทึกหน้าจอ (ค่าเริ่มต้น `Ctrl/Cmd + Alt + R`, Desktop) / ปุ่ม "หยุดแชร์" ของเบราว์เซอร์ (Web)

เมื่อหยุดแล้วจะเปิด **หน้าแก้ไขวิดีโอ**:

- ตัดช่วงต้น/ท้ายด้วยแถบ **เริ่ม** / **จบ** หรือปุ่ม *ตั้งจุดเริ่ม/จบที่ตำแหน่งนี้*
- **บันทึกเป็น**
  - **GIF** — เลือกขนาด (ค่าเริ่มต้น 480p) และเฟรมเรต (ค่าเริ่มต้น 10 fps) เก็บเฉพาะส่วนที่เปลี่ยนในแต่ละเฟรม ไฟล์จึงเล็กสำหรับการอัดหน้าจอ
  - **วิดีโอ MP4 / WebM** — เลือกขนาด เฟรมเรต และคุณภาพ (*ต่ำ* = บิตเรตต่ำ ไฟล์เล็กที่สุด) มีขนาดไฟล์โดยประมาณให้ดู แปลงด้วย WebCodecs จึงเร็วกว่าความยาวคลิปหลายเท่า (ทดสอบใน Chrome: คลิป 10 วินาที ใช้เวลาราว 1 วินาที) ถ้าเบราว์เซอร์ไม่รองรับจะใช้วิธีเล่นคลิปแล้วอัดใหม่แทน ซึ่งใช้เวลาเท่าความยาวคลิป
  - **ไฟล์ต้นฉบับ** — บันทึกไฟล์ที่อัดไว้ตรง ๆ (ไม่ตัด ไม่แปลง)
- **เพิ่มเฟรมนี้ลงในแคนวาส** — นำภาพเฟรมปัจจุบันไปวางเป็นรูปในตัวแก้ไขภาพ
- ลากไฟล์วิดีโอมาวาง (หรือเลือกด้วยปุ่มเพิ่มไฟล์) เพื่อเปิดในหน้าแก้ไขวิดีโอและแปลงเป็น GIF ได้เช่นกัน

> ไม่บันทึกเสียง · บน macOS ต้องอนุญาต Screen Recording ให้แอปใน System Settings › Privacy & Security ก่อน (ครั้งแรกระบบจะถาม) · MP4 จะมีให้เลือกเฉพาะเมื่อเบราว์เซอร์/ระบบรองรับการเข้ารหัส H.264

### จับภาพแบบเลื่อนหน้าจอ (ภาพยาว)

จับหน้าเว็บ แชต หรือเอกสารที่ยาวเกินจอจาก**โปรแกรมไหนก็ได้** ให้เป็นภาพนิ่งภาพเดียว

1. กดปุ่ม **จับภาพแบบเลื่อนหน้าจอ** (อยู่ในกลุ่ม *จับภาพหน้าจอ* คู่กับปุ่มบันทึกวิดีโอ) หรือ `Ctrl/Cmd + Alt + S` หรือเมนู Tray → *จับภาพแบบเลื่อนหน้าจอ…* (Desktop)
2. เลือกหน้าต่างที่จะจับ (เลือก*หน้าต่าง*จะได้ภาพสะอาดกว่า*ทั้งหน้าจอ*) แล้วกด **เริ่มจับภาพ**
3. ไปที่หน้าต่างนั้นแล้ว**เลื่อนลงช้าๆ** จนสุด — แถบด้านบนจะแสดงความสูงของภาพ ถ้าขึ้นว่า *เลื่อนช้าลง* ให้เลื่อนกลับขึ้นไปจุดที่ค้างแล้วค่อยๆ เลื่อนต่อ
4. กด **หยุด** (หรือปุ่มลัดเดิม / คลิกไอคอน Tray) — ภาพยาวจะถูกเพิ่มลงในแคนวาสทันที แก้ไข วาด หรือบันทึก PNG ต่อได้ตามปกติ

หลักการ: แอปดึงภาพจากหน้าต่างประมาณ 8 ภาพต่อวินาที เทียบแต่ละภาพกับภาพก่อนหน้าเพื่อหาว่าเลื่อนไปกี่พิกเซล แล้วต่อเฉพาะส่วนที่เลื่อนเข้ามาใหม่ แถบหัว/ท้ายที่อยู่กับที่ (เช่น แถบเมนูที่ติดด้านบน) จะมีแค่ครั้งเดียว ประมวลผลในเครื่องทั้งหมด

> ข้อจำกัด: เลื่อนเร็วเกินไปจนภาพสองภาพไม่ซ้อนกันจะต่อไม่ได้ (เลื่อนกลับไปจุดที่ค้างแล้วจะต่อให้เอง) · ส่วนที่ขยับเอง เช่น วิดีโอหรือ animation อาจทำให้ต่อผิด · หน้าที่ซ้ำกันเป็นแพทเทิร์นหรือมีพื้นที่ว่างยาวๆ อาจต่อคลาดได้ · ภาพยาวได้สูงสุดประมาณ 32,000 พิกเซล (ขีดจำกัดของ canvas) · แอปไม่เลื่อนหน้าให้เอง ต้องเลื่อนด้วยตัวเอง

## การทำงานเบื้องหลังของ Desktop

- **ปิดหน้าต่างแล้วโปรแกรมยังทำงานอยู่ใน System Tray** — คลิกไอคอนเพื่อเปิดอีกครั้ง หรือคลิกขวา → **Quit** เพื่อปิดจริง

- ปุ่ม **Paste** และ **Copy** ใช้ Clipboard API ซึ่งต้องเปิดผ่าน `localhost` หรือ HTTPS และอาจขอสิทธิ์จากเบราว์เซอร์ หากปุ่ม Paste ใช้ไม่ได้ ให้กด `Ctrl/Cmd + V` แทน

## ความเป็นส่วนตัว

**สรุป: Zcreenshot ไม่ส่งข้อมูลใดๆ ออกจากเครื่อง ไม่มีบัญชีผู้ใช้ ไม่มี analytics หรือ tracking และไม่เก็บรูป วิดีโอ หรือการบันทึกหน้าจอไว้เอง** ทุกอย่างอยู่ในหน่วยความจำ (RAM) ระหว่างใช้งาน ไฟล์จะถูกเขียนลงเครื่องก็ต่อเมื่อคุณกดบันทึก และเขียนไปยังตำแหน่งที่คุณเลือกหรือโฟลเดอร์ Downloads เท่านั้น

### ข้อมูลแต่ละอย่างอยู่ที่ไหน

| ข้อมูล | อยู่ที่ไหน | หายไปเมื่อไร |
|--------|-----------|---------------|
| รูปที่วาง / ลาก / เปิด และสิ่งที่วาดบนแคนวาส | RAM | ปิดแอป, รีเฟรชหน้า หรือกดล้างทั้งหมด |
| ภาพระหว่างจับภาพแบบเลื่อนหน้าจอ | RAM — เก็บเฉพาะส่วนที่ต่อแล้ว ไม่เก็บทุกเฟรม | หยุดจับภาพ (ภาพที่ได้ไปอยู่บนแคนวาสเหมือนรูปอื่น) |
| วิดีโอที่บันทึกหน้าจอ | RAM จนกว่าจะปิดหน้าแก้ไขวิดีโอ | ปิดหน้าแก้ไขวิดีโอ (ถ้ายังไม่ได้บันทึก แอปจะถามก่อน) |
| การแปลงเป็น GIF / MP4 / WebM | ประมวลผลในเครื่องทั้งหมด ไม่อัปโหลดไปไหน | – |
| ภาพตัวอย่างหน้าจอ/หน้าต่างในหน้าต่างบันทึก (Desktop) | RAM | ปิดหน้าต่างบันทึก |
| ประวัติคลิปบอร์ด (Desktop) | RAM — ระหว่างที่แอปเปิดอยู่ แอปจะอ่านคลิปบอร์ดทุก 1 วินาที เพื่อเก็บ**เฉพาะรูปภาพ** 10 รูปล่าสุด (ไม่เก็บข้อความ) | ออกจากแอป, กด **ล้างประวัติ** หรือลบทีละรูป |
| ประวัติรูป (Web) | RAM ของแท็บนั้น | รีเฟรชหรือปิดแท็บ |
| ไฟล์ที่คุณกดบันทึก (PNG / GIF / วิดีโอ) | ตำแหน่งที่คุณเลือก หรือ Downloads | คุณจัดการเอง |

| ชื่อ | เก็บที่ | เนื้อหา |
|------|---------|---------|
| `zcreenshot.locale` | localStorage | ภาษาที่เลือก |
| `zcreenshot-width` | localStorage | ความหนาเส้นที่ใช้ล่าสุด |

นอกจากนี้ เวอร์ชันเว็บเก็บ**ไฟล์ของตัวแอป**ไว้ใน Cache Storage ของเบราว์เซอร์ เพื่อให้เปิดใช้แบบออฟไลน์ได้ (ไม่มีข้อมูลของคุณ) ส่วนแอป Desktop เก็บข้อมูลเบราว์เซอร์ของตัวเอง (localStorage และแคชไฟล์แอปข้างต้น) ไว้ในโฟลเดอร์ข้อมูลของแอป เช่น `%APPDATA%\Zcreenshot` บน Windows หรือ `~/Library/Application Support/Zcreenshot` บน macOS (ถ้ารันจากซอร์สโค้ด ชื่อโฟลเดอร์จะเป็น `zcreenshot`) ลบโฟลเดอร์นี้หรือล้างข้อมูลเว็บไซต์ในเบราว์เซอร์ได้ทุกเมื่อ

### การเชื่อมต่ออินเทอร์เน็ต

- **Web**: เชื่อมต่อเฉพาะเซิร์ฟเวอร์ที่โฮสต์แอป เพื่อโหลดและอัปเดต**ไฟล์ของตัวแอป** ไม่มีการส่งรูป วิดีโอ หรือข้อมูลใดๆ ของคุณ
- **Desktop**: ไม่มีการเชื่อมต่อเลย (ปิดการดาวน์โหลดพจนานุกรมตรวจคำสะกดของ Electron ไว้ด้วย)
- ลิงก์ GitHub และ Ko-fi (สนับสนุนผู้พัฒนา) บนแถบเครื่องมือจะเปิดก็ต่อเมื่อคุณคลิกเท่านั้น (Desktop เปิดในเบราว์เซอร์ของเครื่อง)

### พิสูจน์ (ตรวจสอบได้ด้วยตัวเอง)

1. **Content-Security-Policy ใน `index.html`** ข้อนี้คือตัวล็อกหลัก:

   ```
   default-src 'self'; img-src 'self' blob: data:; media-src 'self' blob:; style-src 'self'; script-src 'self'; worker-src 'self' blob:
   ```

   ไม่มี `connect-src` เบราว์เซอร์จึงใช้ `default-src 'self'` แทน ผลคือ `fetch`, XHR, WebSocket และ `sendBeacon` ไปยังเซิร์ฟเวอร์อื่น**ถูกเบราว์เซอร์บล็อก** แม้จะมีโค้ดพยายามส่งก็ตาม (รวมถึงไลบรารีภายนอก) และทุกรายการอนุญาตเฉพาะ `'self'`, `blob:` (ข้อมูลในเครื่อง) และ `data:` เท่านั้น
2. **เทสต์อัตโนมัติ `tests/privacy.test.js`** รันทุกครั้งที่สั่ง `npm test` (หรือ `node --test tests/privacy.test.js`) และจะ fail ถ้ามีการเปลี่ยนโค้ดที่ทำให้ข้อความในหัวข้อนี้ไม่จริง โดยตรวจว่า:
   - CSP ยังอนุญาตเฉพาะแอปเอง ไม่มีโดเมนภายนอก และไม่มีการเพิ่ม `connect-src`
   - โค้ดของแอปไม่มีคำสั่งส่งข้อมูลเครือข่าย (`fetch`, `XMLHttpRequest`, `WebSocket`, `sendBeacon`, `EventSource`, `RTCPeerConnection`) ยกเว้น Service Worker ที่โหลดไฟล์ของแอป (GET เท่านั้น)
   - โปรเซสหลักของ Desktop ไม่โหลดโมดูลเครือข่าย (`http`, `https`, `net`, `electron.net` ฯลฯ) และปิดตรวจคำสะกดไว้
   - ไลบรารีแปลงวิดีโออ่านจากไฟล์ในเครื่องเท่านั้น (`BlobSource` ไม่ใช่ URL)
   - ไม่มีที่อยู่เว็บในโค้ด นอกจากลิงก์ GitHub และ Ko-fi ในหน้าแอป
   - ทุกอย่างที่แอปบันทึกลงเครื่องตรงกับตารางด้านบน ถ้ามีการเพิ่มที่เก็บข้อมูลใหม่โดยไม่อัปเดตตาราง เทสต์จะ fail
3. **ค้นโค้ดเอง**: คำสั่งนี้ควรเจอแค่บรรทัดเดียวใน `sw.js`

   ```bash
   grep -nE "fetch\(|XMLHttpRequest|WebSocket|sendBeacon|EventSource" *.js --exclude=mediabunny.min.js
   ```

4. **ลองตัดอินเทอร์เน็ต**: ปิด Wi-Fi แล้วใช้งานต่อ (Web ต้องเปิดผ่าน `http(s)` อย่างน้อยหนึ่งครั้งก่อน) ทั้งวางรูป บันทึกหน้าจอ แปลงเป็น GIF/วิดีโอ และบันทึกไฟล์ ใช้ได้ครบ
5. **ดูใน DevTools**: เปิดแท็บ **Network** (Web: `F12` · Desktop: เมนู View › Toggle Developer Tools) แล้วใช้งานตามปกติ จะเห็นแค่การโหลดไฟล์ของแอปเองจากเซิร์ฟเวอร์ที่โฮสต์ (Web) หรือไฟล์ในเครื่อง (Desktop)

> ขอบเขตของคำยืนยันนี้คือ**ตัวแอป Zcreenshot** ส่วนเบราว์เซอร์หรือระบบปฏิบัติการอาจมีนโยบายเก็บข้อมูลของตัวเอง ซึ่งอยู่นอกการควบคุมของแอป สิทธิ์บันทึกหน้าจอเป็นของระบบปฏิบัติการ/เบราว์เซอร์ และระบบจะแสดงสัญลักษณ์ว่ากำลังแชร์หน้าจอตามปกติ

| `npm start` | รันแอป Electron |
| `npm test` | รันเทสต์ (`node --test`) |
| `npm run icon` | สร้างไอคอนใน `build/` |
| `npm run build:web` | สร้างโฟลเดอร์ `web/` สำหรับ PWA |
| `npm run serve:web` | เซิร์ฟเวอร์ทดสอบ PWA ที่ `localhost:5173` |
| `npm run dist:win` | สร้างตัวติดตั้ง Windows (NSIS + Portable) ลง `dist/` |
| `npm run dist:mac` | สร้าง `.dmg` สำหรับ macOS (ต้อง build บนเครื่อง Mac) |

### โครงสร้างโปรเจกต์

```
main.js        โปรเซสหลักของ Electron (หน้าต่าง, Tray, ปุ่มลัด, single instance)
capture-service.js  (main) รายการหน้าจอ/หน้าต่างให้เลือกบันทึก + อนุญาต getDisplayMedia
global-shortcuts.js (main) ปุ่มลัดทั้งระบบ: โหลด/บันทึก/ลงทะเบียน
shortcuts.js   รายการปุ่มลัดและค่าเริ่มต้น + ตัวช่วยอ่าน/แสดง/ตรวจปุ่มซ้ำ (โค้ดล้วน ทดสอบด้วย node ได้)
shortcut-settings.js  หน้าต่างตั้งค่าปุ่มลัด + ตัวจับคู่ปุ่มที่โมดูลอื่นเรียกใช้
recorder.js    หน้าต่างบันทึกหน้าจอ + MediaRecorder (โหมดวิดีโอ และโหมดจับภาพแบบเลื่อน)
scroll-capture.js  อ่านเฟรมจากหน้าจอระหว่างเลื่อน แล้วรวมเป็น PNG
scroll-stitch.js   หาระยะเลื่อน/แถบหัวท้ายที่อยู่กับที่ แล้วต่อภาพ (โค้ดล้วน ทดสอบด้วย node ได้)
video-editor.js  หน้าแก้ไขวิดีโอ: ตัดช่วง, บันทึกเป็น GIF / MP4 / WebM
mediabunny.min.js  ไลบรารีแปลงวิดีโอ (ภายนอก ดูหัวข้อ "ไลบรารีภายนอก")
gif-encoder.js, webm-duration.js, video-options.js   โค้ดล้วน (ทดสอบด้วย node ได้)
preload.js     สะพานเชื่อม main ↔ renderer (contextIsolation)
index.html     หน้า UI
scene.js       ตรรกะฉาก/มุมมองล้วน ๆ ไม่แตะ DOM (ทดสอบด้วย node ได้)
renderer.js    canvas, การลาก/ซูม, วาง/บันทึก/คัดลอก
style.css      สไตล์
sw.js, manifest.webmanifest   ส่วนของ PWA
scripts/       สคริปต์สร้างไอคอน / build web / เซิร์ฟเวอร์ทดสอบ
tests/         เทสต์ (เช่น scene.test.js)
web/           ผลลัพธ์จาก build:web (สร้างใหม่ทุกครั้ง อย่าแก้ตรงนี้)
dist/          ผลลัพธ์จาก electron-builder
```

### ความปลอดภัย

- Electron ตั้งค่า `contextIsolation: true`, `nodeIntegration: false`, `sandbox: true`
- มี Content-Security-Policy จำกัดให้โหลดเฉพาะทรัพยากรจากแหล่งเดียวกัน (ยกเว้น `worker-src` ที่อนุญาต `blob:` เพราะ Mediabunny สร้าง worker ช่วยงานจาก blob URL)

### ไลบรารีภายนอก

| ไฟล์ | ไลบรารี | สัญญาอนุญาต | หน้าที่ |
|------|---------|-------------|---------|
| `mediabunny.min.js` | [Mediabunny](https://mediabunny.dev) 1.61.6 (ไฟล์ `dist/bundles/mediabunny.min.cjs` จาก npm ไม่ได้แก้ไข) | [MPL-2.0](https://mozilla.org/MPL/2.0/) | แปลงวิดีโอ (ตัด ย่อขนาด เข้ารหัส MP4/WebM) ด้วย WebCodecs |

อัปเดตเวอร์ชัน: `npm pack mediabunny@<เวอร์ชัน>` แล้วคัดลอก `package/dist/bundles/mediabunny.min.cjs` มาทับเป็น `mediabunny.min.js` และแก้เลขเวอร์ชันในตารางนี้
- เซิร์ฟเวอร์ทดสอบป้องกัน path traversal และผูกกับ localhost เท่านั้น
