# Zcreenshot

โปรแกรมต่อภาพสกรีนช็อต: วางหรือลากรูปเข้ามา แล้วจัดเรียง ย่อ/ขยาย ก่อนบันทึกเป็นไฟล์ PNG ภาพเดียว

repo นี้ใช้เก็บไฟล์ดาวน์โหลดเท่านั้น (ไม่มีซอร์สโค้ด)

## ดาวน์โหลด

ไปที่หน้า [Releases](../../releases/latest) แล้วเลือกไฟล์ตามที่ต้องการ

- **Setup** สำหรับติดตั้งบน Windows
- **Portable** รันได้เลยโดยไม่ต้องติดตั้ง
