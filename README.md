# Zcreenshot

โปรแกรมต่อภาพสกรีนช็อต: วางหรือลากรูปเข้ามา แล้วจัดเรียง ย่อ/ขยาย ก่อนบันทึกเป็นไฟล์ PNG ภาพเดียว

ใช้งานได้ 2 แบบ:

| แบบ | เหมาะกับ | ฟีเจอร์เฉพาะ |
|-----|----------|---------------|
| **Desktop (Electron)** | Windows / macOS | ไอคอนใน System Tray, ปุ่มลัดทั้งระบบ `Ctrl/Cmd+Shift+V`, เปิดพร้อมเครื่อง |
| **Web / PWA** | เปิดผ่านเบราว์เซอร์ หรือติดตั้งเป็นแอป | ไม่ต้องติดตั้งโปรแกรม, โฮสต์บน static server ได้ |

---

## การเข้าถึง / การติดตั้ง

### 1) Desktop (Windows)

ไฟล์ติดตั้งอยู่ในโฟลเดอร์ `dist/` (หลังสั่ง `npm run dist:win`):

- `Zcreenshot Setup 1.0.0.exe` — ตัวติดตั้ง (NSIS)
- `Zcreenshot 1.0.0.exe` — แบบ Portable ดับเบิลคลิกใช้ได้เลย ไม่ต้องติดตั้ง

### 2) รันจากซอร์สโค้ด

ต้องมี [Node.js](https://nodejs.org/) ติดตั้งไว้

```bash
npm install
npm start
```

### 3) Web / PWA

```bash
npm run build:web   # สร้างไอคอนและคัดลอกไฟล์ไปที่ ./web
npm run serve:web   # เปิดเซิร์ฟเวอร์ที่ http://localhost:5173
```

- เปลี่ยนพอร์ตได้ด้วยตัวแปร `PORT` เช่น `PORT=8080 npm run serve:web` (PowerShell: `$env:PORT=8080; npm run serve:web`)
- เซิร์ฟเวอร์ผูกกับ `127.0.0.1` เท่านั้น จึงเข้าจากเครื่องอื่นในเครือข่ายไม่ได้
- `localhost` นับเป็น secure context จึงกดติดตั้งเป็น PWA ได้ (ไอคอนติดตั้งในแถบ address bar)
- ถ้าจะให้คนอื่นเข้าถึง ให้นำโฟลเดอร์ `web/` ไปโฮสต์บน static server ใดก็ได้ที่เป็น **HTTPS** (เช่น GitHub Pages, Netlify, Cloudflare Pages) เพราะ Service Worker และการเข้าถึงคลิปบอร์ดต้องใช้ HTTPS

### 4) เปิดไฟล์ `index.html` ตรง ๆ (แบบเร็วที่สุด)

ดับเบิลคลิก `index.html` ที่โฟลเดอร์หลักเพื่อเปิดในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งหรือรันเซิร์ฟเวอร์

- ใช้ได้: วางด้วย `Ctrl/Cmd + V`, ลากไฟล์มาวาง, เลือกไฟล์, จัดวาง, ซูม, Undo และ Save PNG
- ติดตั้งเป็น PWA ไม่ได้ เพราะ Service Worker ลงทะเบียนเฉพาะตอนเปิดผ่าน `http(s)`
- ปุ่ม **Paste** และ **Copy** อาจใช้ไม่ได้ในบางเบราว์เซอร์ เพราะ Clipboard API มักต้องการ secure context ถ้าใช้ไม่ได้ ให้กด `Ctrl/Cmd + V` แทน
- ไอคอนแท็บอาจไม่ขึ้น (ไฟล์ไอคอนอยู่ใน `build/`) ไม่กระทบการใช้งาน
- ไม่มีฟีเจอร์ Tray และปุ่มลัดทั้งระบบ (เฉพาะแอป Desktop)

> หัวข้อนี้เขียนจากการอ่านโค้ด ยังไม่ได้ทดสอบกับทุกเบราว์เซอร์ ถ้าต้องการให้ครบทุกฟีเจอร์ ให้ใช้วิธีที่ 3 (Web / PWA)

## วิธีใช้งาน

### เพิ่มรูป

| วิธี | ทำอย่างไร |
|------|-----------|
| วางจากคลิปบอร์ด | กด `Ctrl/Cmd + V` หรือปุ่ม **Paste** |
| ลากไฟล์มาวาง | ลากไฟล์รูป (หลายไฟล์ได้) มาปล่อยในหน้าต่าง |
| เลือกไฟล์ | ปุ่ม **เพิ่มรูป…** |
| ปุ่มลัดทั้งระบบ (Desktop) | `Ctrl/Cmd + Shift + V` จากที่ไหนก็ได้ — โปรแกรมจะเด้งขึ้นมาพร้อมรูปจากคลิปบอร์ด |

รูปใหม่จะถูกต่อท้ายด้านล่างของรูปเดิมโดยอัตโนมัติ

### จัดวางรูป

- **ย้าย** — ลากรูป (รูปที่คลิกจะขึ้นมาอยู่ด้านหน้า)
- **ปรับขนาด** — ลากจุดสี่เหลี่ยมสีส้มที่มุมขวาล่างของรูปที่เลือก (คงสัดส่วนเดิม)
- **เรียงแนวตั้ง** — จัดทุกรูปเรียงจากบนลงล่างให้ชิดซ้าย
- **เลื่อนมุมมอง** — กด `Space` ค้างแล้วลาก, ลากปุ่มกลางเมาส์, ลากที่พื้นที่ว่าง หรือใช้ล้อเมาส์/ทัชแพด
- **ซูม** — `Ctrl/Cmd + ล้อเมาส์`, `Ctrl/Cmd + +` / `-`, ปุ่ม **Fit** หรือ `Ctrl/Cmd + 0` เพื่อพอดีหน้าจอ
- **Undo** — `Ctrl/Cmd + Z` (ย้อนได้ 50 ขั้น)
- **ลบ** — เลือกรูปแล้วกด `Delete` / `Backspace` หรือปุ่ม **ลบ**; **ล้างทั้งหมด** เพื่อเริ่มใหม่
- กด `Esc` เพื่อยกเลิกการเลือก

### เวอร์ชันและประวัติการอัปเดต

เลขเวอร์ชัน (เริ่มที่ **v0.5**) แสดงอยู่ถัดจากชื่อแอปที่มุมซ้ายบนสุด **กดเมาส์ค้างที่เลขเวอร์ชันประมาณ 0.6 วินาที** เพื่อเปิดประวัติการอัปเดต (ปิดด้วยปุ่ม **ปิด**, `Esc` หรือคลิกพื้นที่นอกกล่อง) ผู้ใช้คีย์บอร์ดกด `Enter`/`Space` ที่ปุ่มเวอร์ชันได้เลย

ออกเวอร์ชันใหม่: เพิ่มรายการไว้บนสุดของ `CHANGELOG` ใน `version.js` และแก้ `version` ใน `package.json` ให้ตรงกัน (มีเทสต์ตรวจ)

### ส่งออก

| การกระทำ | ปุ่ม | ผลลัพธ์ |
|----------|------|---------|
| บันทึก | **Save PNG** / `Ctrl/Cmd + S` | ไฟล์ `zcreenshot-<วันเวลา>.png` ของภาพรวมทั้งหมด (ความละเอียดตามต้นฉบับ ไม่ใส่เงา/พื้นหลัง) |
| คัดลอก | **Copy** / `Ctrl/Cmd + C` | คัดลอกรูปที่เลือก ถ้าไม่ได้เลือกรูปใดจะคัดลอกภาพรวมทั้งหมด |

### ปุ่มลัดทั้งหมด

| ปุ่ม | การทำงาน |
|------|----------|
| `Ctrl/Cmd + V` | วางรูป |
| `Ctrl/Cmd + C` | คัดลอก |
| `Ctrl/Cmd + S` | บันทึก PNG |
| `Ctrl/Cmd + Z` | Undo |
| `Ctrl/Cmd + 0` | พอดีหน้าจอ |
| `Ctrl/Cmd + +` / `-` | ซูมเข้า / ออก |
| `Delete` / `Backspace` | ลบรูปที่เลือก |
| `Space` (ค้าง) + ลาก | เลื่อนมุมมอง |
| `Esc` | ยกเลิกการเลือก |
| `Ctrl/Cmd + Shift + V` | (Desktop) วางจากคลิปบอร์ดทั้งระบบ |

> บน macOS ใช้ `Cmd` แทน `Ctrl`

## การทำงานเบื้องหลังของ Desktop

- **ปิดหน้าต่างแล้วโปรแกรมยังทำงานอยู่ใน System Tray** — คลิกไอคอนเพื่อเปิดอีกครั้ง หรือคลิกขวา → **Quit** เพื่อปิดจริง
- เมนู Tray: *Paste from clipboard*, *Open Zcreenshot*, *Start with system* (เปิดพร้อมเครื่อง), *Quit*
- เปิดได้ครั้งละ 1 หน้าต่างเท่านั้น การเปิดซ้ำจะดึงหน้าต่างเดิมขึ้นมา
- ถ้าปุ่มลัด `Ctrl/Cmd+Shift+V` ถูกโปรแกรมอื่นใช้อยู่ จะใช้เมนู Tray แทนได้

## ข้อควรรู้ (Web)

- ปุ่ม **Paste** และ **Copy** ใช้ Clipboard API ซึ่งต้องเปิดผ่าน `localhost` หรือ HTTPS และอาจขอสิทธิ์จากเบราว์เซอร์ หากปุ่ม Paste ใช้ไม่ได้ ให้กด `Ctrl/Cmd + V` แทน
- รูปที่เพิ่มจะอยู่ในหน่วยความจำของหน้าเว็บเท่านั้น ไม่ถูกอัปโหลดไปไหน และจะหายเมื่อรีเฟรชหน้า

## สำหรับนักพัฒนา

### คำสั่ง

| คำสั่ง | หน้าที่ |
|--------|---------|
| `npm start` | รันแอป Electron |
| `npm test` | รันเทสต์ (`node --test`) |
| `npm run icon` | สร้างไอคอนใน `build/` |
| `npm run build:web` | สร้างโฟลเดอร์ `web/` สำหรับ PWA |
| `npm run serve:web` | เซิร์ฟเวอร์ทดสอบ PWA ที่ `localhost:5173` |
| `npm run dist:win` | สร้างตัวติดตั้ง Windows (NSIS + Portable) ลง `dist/` |
| `npm run dist:mac` | สร้าง `.dmg` สำหรับ macOS (ต้อง build บนเครื่อง Mac) |

### โครงสร้างโปรเจกต์

```
main.js        โปรเซสหลักของ Electron (หน้าต่าง, Tray, ปุ่มลัด, single instance)
preload.js     สะพานเชื่อม main ↔ renderer (contextIsolation)
index.html     หน้า UI
scene.js       ตรรกะฉาก/มุมมองล้วน ๆ ไม่แตะ DOM (ทดสอบด้วย node ได้)
renderer.js    canvas, การลาก/ซูม, วาง/บันทึก/คัดลอก
style.css      สไตล์
sw.js, manifest.webmanifest   ส่วนของ PWA
scripts/       สคริปต์สร้างไอคอน / build web / เซิร์ฟเวอร์ทดสอบ
tests/         เทสต์ (เช่น scene.test.js)
web/           ผลลัพธ์จาก build:web (สร้างใหม่ทุกครั้ง อย่าแก้ตรงนี้)
dist/          ผลลัพธ์จาก electron-builder
```

### ความปลอดภัย

- Electron ตั้งค่า `contextIsolation: true`, `nodeIntegration: false`, `sandbox: true`
- มี Content-Security-Policy จำกัดให้โหลดเฉพาะทรัพยากรจากแหล่งเดียวกัน
- เซิร์ฟเวอร์ทดสอบป้องกัน path traversal และผูกกับ localhost เท่านั้น
